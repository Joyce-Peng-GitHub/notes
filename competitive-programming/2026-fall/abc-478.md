## D. Range Set Insertion Query

> 设置 $n \in \mathbb{N}^*$ 个集合 $(S_i)_{i = 0}^{n - 1}$，初始时均为空集。执行 $m \in \mathbb{N}^*$ 个操作 $((b_i, e_i, v_i))_{i = 0}^{m - 1}$，第 $i$ 次操作执行
> $$
> (\forall j \in \mathbb{N} \cap [b_i, e_i))\ (S_j \gets S_j \cup \{v_i\}).
> $$
> 求执行完所有操作后，各个集合的大小。
>
> 保证 $m,n \leq 2 \times 10^5$，
> $$
> (\forall i \in \mathbb{N} \cap [0, m))\ (b_i,e_i,v_i \in \mathbb{N} \land b_i < e_i \leq n \land 1 \leq v_i \leq m).
> $$

想到了对值分组，但我居然没想到可以对区间进行排序……我想的是暴力用差分来合并区间，那样复杂度就到了 $O(m \cdot n)$。

这个实在是很简单，我懒得写思路了，感觉很明显。我不知道我为甚么没想到。

```cpp
inline void solve() {
	size_t m, n;
	std::cin >> n >> m;
	std::vector<std::vector<std::pair<size_t, size_t>>> occs_of(m);
	for (size_t i = 0; i < m; ++i) {
		size_t beg, end;
		uint32_t val;
		std::cin >> beg >> end >> val;
		--beg;
		--val;
		occs_of[val].emplace_back(beg, end);
	}
	std::vector<size_t> cnts(n + 1);
	for (uint32_t val = 0; val < SC<uint32_t>(m); ++val) {
		auto &occs = occs_of[val];
		std::sort(occs.begin(), occs.end());
		std::vector<std::pair<size_t, size_t>> new_occs;
		for (auto [beg, end] : occs) {
			if (new_occs.empty() || beg > new_occs.back().second) {
				new_occs.emplace_back(beg, end);
			} else {
				assert(new_occs.back().first <= beg && beg <= new_occs.back().second);
				if (end > new_occs.back().second) {
					new_occs.back().second = end;
				}
			}
		}
		for (auto [beg, end] : new_occs) {
			++cnts[beg];
			--cnts[end];
		}
	}
	for (size_t i = 0; i < n; ++i) {
		std::cout << cnts[i] << ' ';
		cnts[i + 1] += cnts[i];
	}
	std::cout << '\n';
}
```

时间复杂度：对各组区间排序 $O(m \log m)$，合并后的区间每个访问一次 $O(m)$，对差分数组做前缀和 $\Theta(n)$，一共 $O(m \log m + n)$。

空间复杂度：$O(m + n)$。

## E. lt and le

> 给定 $n \in \mathbb{N}^*$ 和 $m \in \mathbb{N}^*$ 条约束，尝试构造满足所有约束的 $\vec{a} = (a_i)_{i = 0}^{n - 1} \in (\mathbb{N} \cap [0, n))^n$。每一条约束
> $$
> (strict, u, v)\in \{0, 1\} \times (\mathbb{N} \cap [0, n)) \times (\mathbb{N} \cap [0, n))
> $$
> 表示
> $$
> \begin{cases}
> a_u \leq a_v & (strict = 0) \\
> a_u < a_v & (strict = 1)
> \end{cases}.
> $$
> 保证 $m,n \leq 2 \times 10^5$。

考虑转化成图论问题是显然的。

初步的想法当然是套差分约束模板，但这里的 $m,n \leq 2 \times 10^5$ 如果跑 SPFA 会被菊花图卡掉。显然我们需要利用题中的特殊性质，也就是在差分约束中，差值的限制仅可能为 $\{-1, 0\}$。

下面是题解。

---

先假设所有条件都是不严格的，用 $\leq$ 关系建出有向图 $G = (\mathbb{N} \cap [0, n), E)$。同一**强连通分量**内的点必须相等。强连通分量之间的边可以改为严格小于。

再检查每个严格边是否都跨越强连通分量，如果不是即说明无法构造，否则按缩点后的拓扑序赋值即可。

```cpp
inline void solve() {
	size_t m, n;
	std::cin >> n >> m;
	Graph<void> graph(n);
	std::vector<size_t> lt_edges;
	for (size_t i = 0; i < m; ++i) {
		bool is_strict;
		size_t u, v;
		std::cin >> is_strict >> u >> v;
		--u;
		--v;
		graph.insertEdge(u, v);
		if (is_strict) lt_edges.emplace_back(i);
	}
	auto sccs = graph.tarjanSccs();
	std::vector<uint32_t> vals(n);
	for (size_t i = 0; i < sccs.size(); ++i) {
		for (auto v : sccs[i]) {
			vals[v] = n - i;
		}
	}
	const auto &edges = graph.edges();
	for (auto e : lt_edges) {
		auto edge = edges[e];
		auto [u, v] = edge;
		assert(vals[u] <= vals[v]);
		if (vals[u] == vals[v]) {
			std::cout << "No\n";
			return;
		}
	}
	std::cout << "Yes\n";
	for (auto val : vals) std::cout << val << ' ';
	std::cout << '\n';
}
```

时间复杂度：$\Theta(m + n)$。

空间复杂度：$\Theta(m + n)$。

## F. Min-First Search

> 对于一棵无根树 $T = (\mathbb{N} \cap [0, n), E)\ (n \in \mathbb{N}^*)$，定义 $f(T)$ 为 $\mathbb{N} \cap [0, n)$ 的一个排列，他通过以下方式获得：
>
> 1. 令 $S \gets \{0\}$。令 $\vec{p} =()$。
>
> 2. 重复 $n$ 次：
>
>    1. 令 $x \gets \min S$。
>
>    2. 令 $S \gets S \setminus \{x\}$。
>
>    3. 令 $\vec{p} \gets \begin{bmatrix} \vec{p} \\ x \end{bmatrix}$。
>
>    4. 令
>       $$
>       S \gets S \cup \{y \in V(T): \{x, y\} \in E \land ((\forall i \in \mathbb{N} \cap [0, |p|))\ (p_i \neq y))\},
>       $$
>       即将所有与 $x$ 相邻且未出现在 $\vec{p}$ 中的顶点添加到 $S$ 中。
>
> $f(T)$ 定义为通过以上方式获得的 $\vec{p}$。
>
> 现在给出 $\mathbb{N} \cap [0, n)\ (n \in \mathbb{N})$ 的一个排列 $\vec{a} = (a_i)_{i = 0}^{n - 1}$，保证 $a_0 = 0$，求有多少棵不同的无根树 $T$ 满足 $f(T) = \vec{a}$，答案对 $M = 998244353$ 取模。
>
> 保证 $n \leq 2 \times 10^5$。

考虑 $f(T)$ 的执行过程。

显然我们可以取 $0$ 为根，这样我们每次就是将 $x$ 的所有孩子添加到 $S$ 中。记 $prt_v\ (v \in \mathbb{N} \cap [1, n))$ 表示 $v$ 的父顶点。特别地，规定 $prt_0 = -1$。

题解给出了一个观察：对于 $u,v \in \mathbb{N}\ (v < u < n)$，如果 $u$ 比 $v$ 先出现在 $\vec{p}$ 中，必须满足 $u$ 不晚于 $prt_v$ 被访问到，否则 $v$ 一定会比 $u$ 早出现。注意这是一个**必要不充分**条件。

下面考虑从 $\vec{a}$ 还原。

根据上面的讨论，必须有
$$
(\forall i \in \mathbb{N} \cap [1, n))\ \left(\forall j \in \mathbb{N} \cap \left(a^{-1}_{prt_{a_i}}, i\right)\right)\ (a_j < a_i).
$$
记
$$
pre_i = \max(\{-1\} \cup \{j \in \mathbb{N} \cap [0, i): a_j > a_i\}),
$$
即每个元素之前最后一个比他大的元素的位置。于是上述结论化为
$$
(\forall i \in \mathbb{N} \cap [1, n))\ \left(pre_i \leq a^{-1}_{prt_{a_i}} <i\right).
$$
这是一个充要条件。必要性在上面已经证明，下面证明：只要对每个 $i \in \mathbb{N} \cap [1, n)$ 都任意选择某个 $j \in \mathbb{N} \cap [pre_i, i)$ 使 $prt_{a_i} \gets a_j$，这样得到的 $\vec{prt}$ 就一定构成一棵以 $0$ 为根的树 $T$ 且 $f(T) = \vec{a}$。

因为对于每个 $i \in \mathbb{N} \cap [1, n)$ 都选择恰好一个父亲顶点 $a_j$，且 $j < i$，从任何顶点开始沿父亲关系走，在 $\vec{a}$ 中的位置都一定严格减小，所以

- 无环。
- 最终一定到达唯一没有定义父亲的顶点 $0$，即根节点。

所以 $\vec{prt}$ 构成一棵以 $0$ 为根的树 $T$。

下面用数学归纳法证明这样得到的 $T$ 必定有 $f(T) = \vec{a}$。首先必然 $p_0 = 0$。设我们已经取好了前 $i \in \mathbb{N} \cap [1, n - 1)$ 项，要取出第 $i$ 项。

1. $a_i \in S$。

   因为 $a_i$ 的父亲 $prt_{a_i}$ 在 $\vec{a}$ 中的位置 $a^{-1}_{prt_{a_i}} < i$，所以必然已经扩展过 $prt_{a_i}$，因此 $a_i \in S$。

2. 所有尚未放入 $\vec{p}$ 的且比 $a_i$ 小的顶点都不在 $S$ 中。

   假设 $j \in \mathbb{N} \cap (i, n)$ 处就是这样一个顶点，即 $a_j < a_i$ 且 $(\forall k \in \mathbb{N} \cap [0, |p|))\ (a_k \neq a_j)$。

   因为 $a_i > a_j$ 且 $i < j$，根据 $pre$ 的定义有 $pre_j \geq i$；而 $a_j$ 的父亲的位置满足 $i \leq pre_j \leq a^{-1}_{prt_{a_j}} < j$，所以他的父亲尚未被加入 $\vec{p}$，因此 $a_j$ 也还没被访问到，$a_j \notin S$。

因此 $a_i = \min S$，即此时必定选出 $a_i$ 作为 $p_i$，归纳完成。由此最终得到的 $\vec{p} = \vec{a}$。

另外，可以保证不同的父亲选择一定对应不同的树，因为固定根为 $0$ 后，树的形态由 $\vec{prt}$ 唯一确定。

综上，只需对每个 $i \in \mathbb{N} \cap [1, n)$ 独立地选择一个 $prt_{a_i}$ 满足 $pre_i \leq a^{-1}_{prt_{a_i}} < i$ 即可，这里有 $i - \max\{0, pre_i\}$ 个数可以选，因此答案就是
$$
\prod_{i = 1}^{n - 1} (i - \max\{0, pre_i\}).
$$
暴力求 $\vec{pre}$ 会让时间复杂度为 $\Theta(n^2)$。当然，“找到每个位置之前最大的数”是单调栈的经典应用，所以直接用单调栈跑一遍就行。题解使用了一种更奇妙的办法：
```cpp
inline void solve() {
	constexpr uint32_t MOD = 998244353;
	size_t n;
	std::cin >> n;
	std::vector<size_t> arr(n);
	for (auto &e : arr) {
		std::cin >> e;
		--e;
	}
	assert(n && arr.front() == 0);

	std::vector<size_t> pre_gts(n);
	uint32_t ans = 1;
	for (size_t i = 1; i < n; ++i) {
		auto &p = pre_gts[i];
		p = i - 1;
		while (p && arr[p] < arr[i]) p = pre_gts[p];
		ans = SC<uint64_t>(ans) * (i - p) % MOD;
	}
	std::cout << ans << '\n';
}
```

1. 正确性：

   设当前 $pre_i = j$，且 $a_j < a_i$。因为 $j < i$，所以 $pre_j$ 已经求出，根据定义，
   $$
   (\forall k \in \mathbb{N} \cap (pre_j, j))\ (a_k < a_j < a_i),
   $$
   所以 $(pre_j, j)$ 这一段元素也不可能成为 $pre_i$，直接跳过即可，即令 $pre_i \gets pre_j$。

2. 与单调栈的等价性：

   要处理位置 $i \in \mathbb{N} \cap [1, n)$ 时，栈顶是刚处理完的 $i - 1$。因为我们需要找出每个元素的前一个比他大的元素，所以需要维护栈内下标对应元素从栈底到栈顶递减，即

   ```cpp
   for (size_t i = 0; i < n; ++i) {
   	while (stk.size() && arr[stk.back()] < arr[i]) {
   		stk.pop_back();
   	}
   	pre_gts[i] = (stk.empty() ? 0 : stk.back());
   	stk.emplace_back(i);
   }
   ```
   
   题解方法相当于用 `pre_gts` 保存每个元素在栈中时他下面的元素，`p = pre_gts[p]` 实际上就是在将 `p` 出栈。
   
   |    单调栈    |                 指针链                 |
   | :----------: | :------------------------------------: |
   | 首次获取栈顶 |              `p = i - 1`               |
   |   弹出栈顶   |            `p = pre_gts[p]`            |
   | 查询当前栈顶 |                  `p`                   |
   | 当前元素入栈 | 定 `pre_gts[i]`，下一轮从 `i + 1` 开始 |
   
   因此各个元素入栈一次，出栈最多一次，时间复杂度 $O(n)$。
