# AGENTS.md

## 文献资料

- 优先查阅 `references/` 目录中已经保存的文献，确认现有资料不能满足需要后再进行网络搜索。
- 需要联网补充资料时，优先选择论文原文、官方文档、标准等可靠的一手来源；将实际采用的文献下载并保存到 `references/` 目录，避免只依赖搜索结果摘要或无法追溯的二手材料。

## 讲解知识基线

- 当用户要求讲解某个概念或某段论文时，将当前文件夹中除 `references/` 目录以外的用户编写内容视为用户已经掌握的知识。
- 对用户编写内容中已经出现的知识无需重复讲解；仅在相关内容之间建立联系或说明其在当前语境中的作用时提及即可。
- 用户编写内容中没有出现的概念、背景和前置知识，应当视为用户尚不了解；在讲解涉及这些内容时，应追根溯源地补充定义、背景、必要的前置知识和推导，直到能够理解当前内容为止。
- `references/` 中的文献不属于用户已经掌握的知识，不能仅因为相关内容出现在这些文献中就省略讲解。

## Typst 编写规范

- 使用 Typst 自身的语法和解析规则，不要直接套用 LaTeX 写法。
- 特别注意数学模式中下标与函数调用之间的空格。例如，表示函数 `f` 的第 `i` 个分量作用于 `x` 时，应写作 `f_i (x)`，不要写成 `f_i(x)`；后者会被 Typst 解析并渲染为下标 `i(x)`，即相当于 $f_{i(x)}$。
- 完成修改后应编译 Typst 文档并检查输出，尤其确认公式的下标、括号和函数调用均按预期渲染。
